El mapa de la base de datos

Noventa y tres tablas agrupadas por área. No hay una tabla de candidatos: un candidato es un usuario que postuló, y sus datos personales viven en persona, la misma tabla que usa el equipo de Renaser. Toda entidad de negocio pertenece además a una organización.
